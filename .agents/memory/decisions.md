# Notes and decisions

Choices made on purpose, and things about the project that aren't obvious from the code. Read it before changing anything it covers. Add an entry when you make a choice a later reader might undo by accident, or find a quirk they would trip over; change or remove an entry when it stops being true.

- **Request shape:** `claude-haiku-5-5` by default (Sonnet 5.5 selectable), adaptive thinking with summarized display, effort `low` by default, `max_tokens` 8000 (thinking counts against it; 1024 risked cutting off tool calls). Tools have `eager_input_streaming`, so every tool input is validated with zod before running.
- **Caching:** an explicit breakpoint on the system block caches tools + system, and top-level automatic caching covers the snapshot so round 2 of a command reads it from cache. Optional 1-hour TTL in Settings. The tool order in `ai/tools/catalog.ts` is part of the cached prefix: append, never reorder.
- **Page access:** `<all_urls>` is requested up front. Optional per-site permissions would need a permission prompt from the popup on first `get_page_text` for each site (the worker can't show one), which works against convenience. Revisit before any store release.
- **Bypass all mode:** `bypass` skips every confirmation, `alwaysAsk` and `when: 'always'` included. The page guardrail refusals (passwords, card and bank fields, the final pay or place-order button) still apply: they block the action rather than ask, so no mode lifts them.
- **Browsers:** Hermod is a Chromium Manifest V3 extension, not a Vivaldi one. It is used day to day in Vivaldi and the end-to-end suite runs in Chromium. Vivaldi-specific handling stays, but must not break other Chromium browsers.
- **Web panels:** Vivaldi reports web panels as tabs. Tabs whose `vivExtData` has a `panelId` are hidden from the snapshot and rejected by every tool. Check this against your Vivaldi version.
- **Quick window:** Vivaldi can open the toolbar popup in another window, so the `open-prompt` shortcut opens Hermod in a window of its own over the window in use (`lib/detached-window.ts`).
- **Design:** the UI follows the [Baritone design system](https://claude.ai/artifact/2y3oeBNsQtCBxy5mn13dKb): warm neutrals, `surface` islands on a `ground` page, one clay accent, Inter for the interface and Petrona for titles. Fonts are bundled through Fontsource, so nothing loads from Google at runtime. The `components/ui` primitives carry its recipes, so prefer tokens (`ink-2`, `line`, `sage-ink`) and the control heights (`h-[var(--control-h)]`) over raw Tailwind colours and ad-hoc `h-*`. Hermod is the source for part of that system: its Field, Menu (select list) and Card recipes come from `components/ui/input.tsx`, `select.tsx`, `textarea.tsx`, `label.tsx` and `card.tsx`, and its Settings component from `entrypoints/options/App.tsx`. Mirror a deliberate change to those into the design system.
- **Testing:** `.env` (git-ignored) is only for local testing; the extension never reads it.
- **Chat export:** `export_conversation` reads a chat through the endpoints the site's own web app uses (ChatGPT `/api/auth/session` then `/backend-api/conversation/<id>`; Claude `/api/organizations` then `chat_conversations/<id>?tree=True&rendering_mode=messages`), fetched inside the tab so the user's session applies and the token never leaves the page. Neither is documented: when a site changes, the zod schemas in `chat-transcript.ts` fail with a message naming the site. The transcript never goes through the model (cost, and it would paraphrase). It keeps message text and attachment names only, not tool calls, artifacts, canvases or images. It is saved as a base64 `data:` URL because the service worker can't make blob URLs, and Chrome caps URLs at 2 MB, so chats over about 1.5 MB of text are refused.
- **Transcript format:** each exported message sits in a `<user>` or `<assistant>` tag on its own line, with blank lines inside so the message still renders as Markdown. A `## You` style heading can't be used, because replies contain Markdown headings of their own. A message that has `</assistant>` on a line of its own outside a code block would still confuse a simple parser; that is accepted as rare.
- **Slash commands:** they run in the worker without the model (`lib/slash-commands.ts`, `runSlashCommand` in `background.ts`), so they make no API call, cost nothing and work with the key locked, and they don't add a turn to the thread: the popup shows the result as a notice above the prompt. "This tab" follows the snapshot's rules: the active tab of the last focused normal window, never Hermod's own tab.
- **Markdown in answers:** Streamdown styles what it renders (list bullets, headings, tables) with Tailwind classes inside its own bundle, so `assets/tailwind.css` has an `@source` for `node_modules/streamdown/dist`. Without it, lists render with no bullets.

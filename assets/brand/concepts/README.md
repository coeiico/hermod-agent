# Hermod logo concepts

Created 2026-10-13 using the built-in image generation tool.

These raster concept boards explore logos and matching light/dark app icons. The Messenger was selected and expanded into the [production icon set and README banner](../README.md). These boards remain as the original design exploration.

- [01 — The Messenger](01-messenger.png): an original Norse traveler profile, the strongest character direction.
- [02 — The Night Rider](02-night-rider.png): a horse-head emblem inspired by Hermod's journey on Sleipnir.
- [03 — The Wayfinder](03-wayfinder.png): an H monogram crossed by a forward route.

Palette: clay `#b6613f`, cream `#f3ebe4`, near-white `#fdfdfc`, charcoal `#1e1e1c`; dark-theme clay `#da8e6f`. Existing display/UI typefaces: Petrona / Inter.

Mythology reference: [Hermod — Lex](https://lex.dk/Hermod).

## Generation prompts

### Concept 1

```text
Use case: logo-brand.
Create a polished landscape logo concept presentation for "Hermod", a browser AI agent that carries out user commands. This is exploratory original brand design inspired by the Norse mythological Hermod, NOT Marvel or an existing franchise.
Palette MUST retain the current brand: clay #b6613f, warm cream #f3ebe4, near-white #fdfdfc, charcoal #1e1e1c. Dark samples can use charcoal with lighter clay #da8e6f. No other saturated colors.
Style: memorable, bold, sophisticated, warm, distinctive; flat vector-like artwork, crisp contours, generous negative space, graphic silhouettes that can be redrawn as SVG. Character and motion without excessive detail. No gradients, texture, 3D, neon, stock clipart, esports crest, ornate borders, fake runic text, generic AI sparkle.
Composition: editorial concept board with a large dominant logo mark and "Hermod" wordmark in the upper/main area, plus a lower row of matching square app icon on cream, matching square app icon on charcoal, and a solid single-color reproduction. All uses share the EXACT SAME symbol. App icons should be bold enough for a browser toolbar. The wordmark should complement the project's Petrona serif display type and Inter UI type; restrained customized serif is appropriate. Exact text only: "Hermod" plus the provided concept title. No invented slogans or paragraphs. Clean generous margins, no mock objects.
Concept title (verbatim): "01 / THE MESSENGER"
Primary request: A charismatic original Hermod character mark: a compact side profile of a youthful, alert Norse traveler facing right, wearing a simple low-domed traveling helmet with a swept-back cloak or scarf suggesting rapid movement. A clever slight smile and decisiveness, not a grim warrior. Sculpt the profile with bold clay shapes and cream negative space. No horned helmet, wings, weapon, beard, crown, comic likeness, or tiny facial details. The silhouette should feel like a capable adventurous companion with personality, not a security or sports mascot. Make this character the sole symbol; do not add horse, H, envelope or arrow. Design a reduced faithful icon using the same essential profile.
```
